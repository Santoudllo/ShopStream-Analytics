# ShopStream Analytics

Bienvenue dans le projet **ShopStream Analytics**.

## Instructions pour les étudiants

Pour récupérer et utiliser l'environnement du projet, suivez les étapes suivantes :

1. **Forker** ce dépôt GitHub sur votre propre compte.
2. **Cloner** votre fork sur votre machine :

```bash
git clone https://github.com/VOTRE-UTILISATEUR/ShopStream-Analytics.git
```

3. Accéder au dossier du projet :

```bash
cd ShopStream-Analytics
```

4. Ouvrir le fichier `README-ENVIRONNEMENT.md` et suivre toutes les instructions d'installation et de configuration dans l'ordre indiqué.

**Important :** toutes les étapes décrites dans `README-ENVIRONNEMENT.md` doivent être réalisées avant de commencer les travaux pratiques.
